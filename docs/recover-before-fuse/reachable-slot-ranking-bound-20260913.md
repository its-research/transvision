# 因果根可达性的事件完整排序上界

本实现继续加强不可恢复的固定 Top-K 基线，不增加历史身份恢复能力。它已完成真实 train 序列 `0000` 的全部 195 个事件，解决了[稠密与稀疏赋值版本](slot-assignment-ranking-bound-20260913.md)在这个序列的容量失败；原生 car 指标却低于逐节点 beam。原有候选支持、行势、旧保留类、状态更新与资源上限不放宽。容量成功与身份性能结论分别记录。

## 1. 旧放松中可以收紧的部分

旧源帧赋值上界把每行所有未决父边的质量合并为一个量，并允许它连接任意已知根或该行的私有列。这个放松是合法上界，但忽略了因果支持：一个未决父节点不一定能够到达任意旧根；多个观测还可能争用同一个尚未确定的新生根。

新后端 `reachable_slot_bound_joint_beam` 对当前固定前缀传播根可达集合，只将可能到达某根的父边计入该根的行权重上界。它不删除模型中的正父边，也不把小权重近似为零。原稠密与稀疏后端保留。

## 2. 可达集合覆盖合法根的证明

沿用原模型的因果编号、正的新生／父边势和源帧互斥条件。固定深度为 \(d\) 的合法根前缀 \(r_{<d}\)，记源帧槽位为 \(s_i\)，父候选集合为 \(P_i\)。普通源帧中，同一身份最多占据一个观测。预留源 \(-1\) 的锚点不施加这个互斥。

对已处理节点 \(p<d\)，令 \(C_p=\{r_p\}\)。对未处理节点 \(i\ge d\)，按因果顺序递推：

\[
C_i=\{i\}\cup
\bigcup_{p\in P_i}\big(C_p\setminus E_i\big),
\]

其中先排除同一普通源帧的直接父边。\(E_i\) 包含已经被固定前缀占用槽位 \(s_i\) 的根，以及出生槽位就是 \(s_i\) 的其他根。源 \(-1\) 不使用这些排除条件。这里的集合只编码必要可达条件，不编码全部联合合法性。

取任意合法后缀。若节点 \(i\) 新生，则真实根为 \(i\in C_i\)。否则节点 \(i\) 至少有一条父边连接到具有相同真实根的较早节点 \(p\)。由因果归纳，真实根属于 \(C_p\)；合法源帧互斥保证它不在 \(E_i\)。所以真实根属于 \(C_i\)。归纳起点是固定前缀的单元素集合。

因此，排除不可达根不排除任何合法完整身份类。反过来，属于 \(C_i\) 并不保证与其他节点的根选择联合可行。

## 3. 根特定行势与赋值上界

对 \(r\ne i\)，定义

\[
g_i(r)=\sum_{p\in P_i:\ r\in C_p\setminus E_i}\psi_{ip},
\qquad g_i(i)=b_i.
\]

这里相加的是当前行的不同父边势，不是沿路径连乘的势。同一个父节点存在多条到达根的路径时，其当前行父边只计一次。

对任意合法根配置 \(r\)，当前行真实的类转移权重为

\[
t_i(r)=\begin{cases}
b_i,&r_i=i,\\
\sum_{p\in P_i:r_p=r_i}\psi_{ip},&r_i\ne i.
\end{cases}
\]

由可达覆盖可得 \(t_i(r)\le g_i(r_i)\)。沿用父路径权重按根配置求和可以逐行分解的模型假设，对固定前缀的绝对类权重 \(W_d\)，完整类满足

\[
w(r) = W_d\prod_{i\ge d}t_i(r)
\le W_d\prod_{i\ge d}g_i(r_i).
\]

在每个普通源帧内，对可达根使用容量为一的赋值列。节点自身的新生可以放在私有列，因为同槽位的其他节点不能合法使用它的新生根；其他槽位使用这个新根时，仍使用具有实际根编号的共享列。源 \(-1\) 按独立单行槽位处理。

每个真实合法后缀都能映射成这些源帧赋值的可行解。若 \(z_s\) 是槽位 \(s\) 的最大 log 赋值值，则

\[
\boxed{\max_{r\supset r_{<d}}\log w(r)\le\log W_d+\sum_s z_s.}
\]

这个放松仍然忽略不同槽位之间的联合根一致性。它是单个完整类的排序上界，不是配分函数、遗漏质量或真实身份错误概率。尚未具体化的旧分量笛卡尔组合继续使用原粗分组上界；不能把旧分量编号当作唯一身份根。

实现复用稀疏赋值分解及可行对偶覆盖，不把求解器返回的原始可行解分数冒充上界。浮点处理仍有整体裕量，`formal_numeric_certificate=false` 保持不变。可达性和弱对偶关系是经典依据，不作为论文独立创新主张。

## 4. 资源、语义与回滚

原每事件 50,000,000 个额外排名工作单位、前沿 65,536、组合状态 65,536、单矩阵 262,144 个元素、最多 100,000 次赋值求解均保持不变。新增单次前缀上界查询最多 200,000 个父节点／根传播项，传播与排除检查计入额外排名工作。

工作计数不是 CPU 指令数或相同物理计算量证明。SQL、集合操作、排序、求解器内部操作和状态回放仍需用完整耗时、RSS 与尾延迟衡量。任何容量超限都回滚当前整个事件；不提交未经 Top-K 停止条件检查的输出。

该后端联合考虑原保留类的全部笛卡尔组合和整个新批次。它不从上一事件已删除类中恢复身份，不回写历史预测，不改动 `DetectionCacheV2` 或 car 评价格式。它仍不是已复现的经典 MHT。
