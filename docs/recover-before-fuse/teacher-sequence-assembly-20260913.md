# 独立序列教师的完整 train 汇总

新增 `tools/event_track_v2x/assemble_allocation_teachers.py`，将分别完成的序列教师
合并为可供训练包读取的派生产物。完整序列可以独立执行；不必因为另一个序列失败，
就重新计算已经封存的完整序列。该工具本身不运行推断、不训练参数、不上传文件。

当前真实输入仍在收集，尚未产生完整 46 序列汇总。单序列的运行中快照、已提交数据库
前缀、测试夹具和汇总工具通过测试，都不能代替完整 train 回执。

## 1. 完成条件

正式 CLI 要求提供 46 个独立序列目录及各自 `receipt.json` 的 SHA-256。
所有目录必须来自同一个已封存的 SPD train 协同元数据，恰好覆盖 7,445 个事件。
令原日程为 \(\mathcal S\)，序列 \(s\) 的已完成事件集合为 \(E_s\)，要求

\[
\bigcup_s E_s=\mathcal S,\qquad
E_s\cap E_t=\varnothing\quad(s\ne t),\qquad
\sum_s|E_s|=7445.
\]

计数只是必要条件。实现同时比较每个 `(sequence_id, frame_id)`，不能用重复序列、
其他序列的事件或不同帧集合补足数字。

每个源目录还必须满足：

- 已完成单序列教师回放，并有一致的 `development-teacher-receipt.json`。
- 预测、审计、时延记录、数据库和序列头均与回执一致。
- 使用 learned identity，且仅处理 car；不接受 geometry 试验冒充正式输入。
- 跟踪配置、冻结身份检查点、优先级训练绑定、位姿表、缓存和全部绑定源码一致。
- 完整原始 train 输入已经由教师入口验证，但各源目录仍如实标记为单序列产物。

测试函数允许显式夹具模式，CLI 不提供此开关。夹具汇总不会生成正式完整 train 回执，
也不能通过生产训练包的 46 序列、7,445 事件核验。

## 2. 汇总与再核验

按照序列编号排序，逐字节连接预测、审计和时延文件。数据库复制到新的输出目录，
不使用硬链接，不改写原目录。各序列的预测提交链和最终头保持不变。

汇总计划使用独立类型 `component_allocation_teacher_assembled_train_plan_v1`，
记录全部源目录、源回执和最终单序列回执摘要。它不是一次新的连续回放。
只有完整校验通过后，才写入完成回执。失败保留明确的 `failure.json` 和恢复材料，
不会把未完成复制当成可上传训练包。

`package_allocation_policy_ddp.py` 已支持此类型。打包前重新打开所有源序列，重算
拼接文件摘要，核对复制数据库、配置、执行模式和派生统计。不能只把汇总标志改成
`complete` 或 `full_official_train_verified=True` 就通过验收。

随后沿用原训练数据导出与训练包检查：逐项验证教师目标算术和各分片，再确认重新
导出的全部数值组与待打包数据相同。不会重新加权序列、删除负目标或挑选正收益事件。
上传包仍不包含原教师审计流、完整预测、GT、检测缓存或已有模型权重。

使用方式：

1. 对每个 train 序列完成 `collect_allocation_training.py --development-sequence`。
2. 调用 `assemble_allocation_teachers.py`，为每个序列重复提供
   `--replay DIRECTORY RECEIPT_SHA256`，并提供固定协同元数据和新输出目录。
3. 对完成的汇总目录执行原 `train_allocation_policy.py export`。
4. 使用原 `package_allocation_policy_ddp.py` 核验并打包。
5. 数据和训练包全部就绪后，才提交 ClearML 参数训练；当前仅调度至少四张 A100。

`0000` 以外的失败或未完成序列不会改变已有完整序列的内容，但必须补齐后才可执行
正式全量汇总。该入口尚不包含自动集群调度器。

## 3. 资源统计的含义

不同序列可能并行，也可能复用同一进程。因此只报告源序列运行数，不从目录数量推断
独立进程数。

`elapsed_seconds` 是各源运行耗时之和，不是整个任务的墙钟时间。
`process_peak_rss_bytes` 是各源运行所报告进程高水位的最大值，不是并发任务的总峰值。
对应范围字段明确记录这两点。帧时延分位数从所有原始帧时延重新计算，不能平均各
序列的分位数。它们仍包含教师试算成本，不代表部署时延。

打包再核验会拒绝改写后的范围说明、错误时延分位数、帧数、数据库大小和源不可用计数。
这些统计不是同算力实验结果，不能用于声称加速比或资源优势。
