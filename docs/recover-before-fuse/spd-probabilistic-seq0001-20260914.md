# SPD 序列 0001：JPDA／PKF 实测与硬身份不变性

本轮完成 JPDA-CI、JPDA-Kalman、PKF 三种本地适配的真实回放、原生指标计算和
独立数据库审计。每组均覆盖固定训练序列 `0001` 的 183 帧，使用同一个已完成的
A100 种子 1337 身份模型。没有新训练参数，没有读取 SPD test/test_A 或 V2V4Real test。

三组的 HOTA、IDF1、AMOTA 均低于关闭恢复的 beam 参考。但此前恢复开启与关闭
没有指标差异，所以本轮结果不能证明恢复机制带来收益。三个后端不是三个训练种子，
本轮也不是全 SPD val、公开方法复现或同资源比较。

## 1. 固定实验合同

新增 `run_train_probabilistic_diagnostic.py`，只接受完整官方 train 缓存、固定协同
元数据、匹配的已训练身份检查点和一条完整训练序列。CLI 不提供测试夹具开关、
几何替代模型、关联算法选择、解码器选择或资源上限调参选项。

三个后端均保持既有默认值：LBP、joint-MAP 硬锚点、每 scan 最多 10,000 次迭代、
10,000,000 次消息更新、停止容差 `1e-10`；唯一后端配置差异是连续状态更新器。
原始检测分数不乘未匹配质量。数学与近似条件见
[持久化适配说明](probabilistic-tracking-v2.md)和[单帧核心](probabilistic-baseline-cores.md)。

原始观测、学习势函数、完整日程、参考时刻和实际到达规则与先前 beam 参考一致。
三个后端使用压缩 Gaussian 状态的顺序 scan 更新，不是恢复后端的源状态时刻重放，
因此与 beam 的比较不能称为仅改变压缩或仅关闭恢复的因果消融。

SPD 继续沿用封存适配器的 `car` 类，即原始 `Car/Truck/Van/Bus` 映射，不报告
pedestrian。这不是原始 `Car` 单类表，也不与 V2V4Real 的严格原始 Car 口径混称。
GT 由独立评估器读取，使用之前同一份 183 帧 GT 和 50 m ROI；没有 GT 进入推断。

## 3. 硬身份不变，身份指标仍可能变化

新增 `audit_probabilistic_identity_invariance.py`，从各完整数据库读取硬身份根映射，
逐事件重建历史前缀摘要，再对比条件匹配、输出记录和连续状态。
审计不读取 GT 正文、不重算指标、不重新运行推断。

真实审计结果如下：

- 三组均消费 4,671 个原始观测；所有 183 个事件的完整历史身份根映射相同。
- 259 个条件 scan 的因子、边缘、硬锚点和时刻相同。
- 输出 ID、观测成员、检测分数、出生时刻及最后更新时间相同。
- 相对 JPDA-CI，JPDA-Kalman 与 PKF 各有 182 帧的连续状态不同。
- 尽管硬身份历史不变，三组 IDF1 不同，PKF 的原生 IDS 也从 0 变为 2。

这不是评价器错误。令 $a$ 表示固定原始观测上的硬身份配置，$X$ 表示输出框状态，
$G$ 表示固定 GT。ROI 和几何相似度均依赖 $X$，例如

\[
S_{ij,t}(X,G)=\operatorname{IoU}_{\mathrm{BEV}}(x_{i,t},g_{j,t}).
\]

评价器根据 ROI、相似度和 ID 计算指标，因此一般应写为 $M(a,X;G)$，不能简化为
只依赖身份配置的 $M(a)$。本轮构成一个实际案例：

\[
a_{\mathrm{CI}}=a_{\mathrm{Kalman}}=a_{\mathrm{PKF}},\qquad
X_{\mathrm{CI}}\ne X_{\mathrm{Kalman}},\qquad
\mathrm{IDF1}_{\mathrm{CI}}\ne\mathrm{IDF1}_{\mathrm{Kalman}}.
\]

因此，IDF1／HOTA 变化不能单独证明身份配置更准确或恢复了正确身份。
论文中的有界身份损失 $\ell(a,H)$ 仍需独立定义和核验，不能直接换成这些指标。
本审计证明的是输出与历史映射不变，不证明这些身份映射本身正确。

## 4. 数值与资源审计

四组实际原始因子流摘要均为
`f336a1a94ed42b4040d64de690d36631390b95ff5a381e27b19bcf91c3258a27`。
三个概率后端的每个 scan 均重新核对因子摘要、行列边缘归一化、禁止边零质量、
停止条件、资源计数和硬锚点的一对一结构。

每组共记录 23,309 次 LBP 迭代、1,639,996 次消息更新和 31,642 个状态工作单位。
跨 scan 最大消息残差为 `9.994627347964524e-11`，最大行列归一化误差为
`5.363065547214774e-11`。这些是数值停止条件，不是对真实或精确模型后验的误差上界。
这些后端不报告完整历史模型风险界；缺失值没有补为零。
