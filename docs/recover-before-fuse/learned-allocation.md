# 学习式搜索优先级：模型风险进展蒸馏

`LearnedComponentTracker` 已接入原持久化分量推断器与 `DetectionCacheV2`。学习模块
只选择下一次搜索的分量，不修改候选支持、势函数、身份互斥、区域质量上界或
输出风险计算。默认的确定性分配器继续保留，用于控制变量比较。

本阶段包含离线教师、训练数据导出、三种子拟合、冻结检查点和回放接口。证据
仅来自有限模型及 V2 格式夹具。身份势已完成[真实 full train 三种子四卡开发训练](clearml-ddp-training-20260913.md)；优先级模型尚未完成真实全量训练，双数据集跟踪验证也未完成，不能据此宣称恢复收益或资源优势。

真实教师状态中出现一步目标近零的问题后，新增了独立、默认关闭的
[前沿完整类候选变体](frontier-completion-20260913.md)。它增加操作选择，不改变
原上界定义；原分配器仍保留为对照。

## 1. 学习对象与数学边界

在同一决策时刻，令 $S$ 为当前搜索状态，$c$ 为可展开分量，$\lambda_c$ 为损失
权重。条件 Bayes 候选选择在全局风险回退之前给出的模型 regret 上界为

\[
b_c(S)=\min\{1,\bar\eta_c(S)+\delta_c(S)\},\qquad
\overline{\mathcal R}(S)=\sum_c\lambda_c b_c(S).
\]

$\delta_c$ 是选中动作的条件风险与合法动作风险松弛下界的差。$T_c$ 是原分配器
规定的下一操作：有预算可容纳的旧分支贪心后缀提案，否则一次合法前缀细化。
操作与容量检查共用原实现。教师目标为

\[
y_c(S)=\frac{\lambda_c[b_c(S)-b_c(T_cS)]}{\max\{1,k_c(S)\}},\qquad -1\le y_c(S)\le1,
\]

$k_c$ 是实际计费步骤数；容量无法推进时为零。目标保留负值，不把上界上升
伪装成收益。它是当前模型上界的单位操作进展，不是身份错误、HOTA／IDF1、
精确 Bayes regret 或长期 VoI。界变紧不推出真实错误减少，回退后的实际输出
风险仍须另算。

冻结 tanh MLP 预测 $f_\theta(\phi_c(S))\in[-1,1]$，选择最大预测值对应的分量，
并列按分量编号确定。预测值只用于排序，不进入配分函数、遗漏量或风险界。
任意优先级下，只要原推断器继续维护完整未展开支持和合法上界，
[原分量证明](persistent-components.md)仍适用于最终实际动作。这不证明学习策略
最优、风险界单调下降或有限预算下必能找到有用分支。

若额外知道当前全部候选满足 $|f_\theta-y_c|\le\epsilon$，比较最大预测值两侧
可得 $y_{c^*}\ge\max_c y_c-2\epsilon$。本实现没有这种统一误差证书；训练 MSE
不能代替该假设，该条件结论也不能扩展为多步最优性。

## 2. 因果特征与离线教师

18 个固定特征来自当前搜索状态：损失权重、遗漏上界、条件风险、优化间隙、
模型 regret 上界、显式类熵、前两类分数差、节点／损失节点／显式类／前沿数量、
前沿深度比例、剩余预算比例、操作类别、操作步骤数、前缀数及加权遗漏量。
数量使用 `log1p`，完整名称固定在 `allocation_policy.FEATURES`。

特征不含 GT、身份标签、绝对帧号、未来观测或未来试算结果。源时刻与冻结外观
先进入原身份势，再通过当前统计影响优先级。未到达输入在生成特征之前被拒绝。
前缀互斥、等价父路径求和、分量合并、旧输出不回写、状态重放与超限回滚不变。

`AllocationTeacherTracker` 按原加权遗漏量规则选择实际操作。每个选择点对所有
当前可展开分量各试算一次，再回滚 SQLite 保存点、Python 搜索状态及共享 LRU
的内容、顺序和计数。试算创建的前缀、权重与发现记录不能污染正式轨迹。
它只在当前因子上多做计算，不读取未来帧，也不需要 GT。

同一决策内，另一个分量的操作不会改变当前分量的因子与身份搜索状态。教师
现按精确状态复用试算结果，缓存键包括节点数、修订号、前缀数、active／frontier
句柄集合、具体操作、有效局部容量、决策时刻、损失作用域、回退动作、权重及
试算前风险界。全局容量变化只有在实际裁剪后的局部容量不变时才允许复用。
剩余预算仍用于每次重新确定操作，不凭一个相同的学习特征向量判断状态等价。

缓存每个分量只保留一个结果，最多保存 65,536 个 active／frontier 句柄引用；
超限仅淘汰可重算的试算缓存，不删除任何身份假设。事件结束、分量合并后的
下一事件或异常重试均从空缓存开始。命中仍计入原教师请求预算，全部候选和
原标签目标保持不变；实际试算次数与复用次数单独记录。复用不增加训练样本
预算，也不把离线试算开销混入部署延迟。真实状态上的对照见
[教师试算复用记录](teacher-probe-reuse-20260913.md)。

样本来自确定性行为策略的状态分布，不是学习策略的闭环采样。部署分布变化
尚未由 DAgger、强化学习或重采样解决，不能忽略这一学习误差来源。

## 3. train 合同与检查点

正式采集只接受封存的 SPD train 缓存：46 个序列、16338 个源帧，按 7445 个
合作配对输出执行。配对元数据提供 SHA256，序列及帧必须在缓存中。这里只用
配对快照，不是全部异步传感器流。不读 GT、SPD val、test 或 test_A。
底层原始观测接口用于单元测试，不能单独证明数据划分。

导出只保留特征矩阵与目标向量，序列标识在分片清单中，不进入模型。完整回放、
文件哈希、源码和最终全 train 回执通过检查后，才能标记完整 train 轨迹。

用固定哈希排序选前 `max(1, floor(N/5))` 个 train 序列作为优先级模块留出集，
其余用于优化。划分在拟合前写入计划；固定最后一轮，不按留出结果选择检查点。
种子为 1337、2027、3407。损失先对每个选择点内候选取 MSE 均值，再对选择点
平均；数据逐序列逐选择点读取，单个选择点另有候选数量上限。

`full_official_train_trace=True` 只表示教师轨迹来自完整 train 队列，不表示全部
train 序列参与了优先级模块优化。留出序列排除，尚未进行全 train 最终重拟合。
上游检测器／身份势可能使用过留出序列，故 `strict_pipeline_isolated_selection=False`。
不能把局部留出称为全流程隔离。

权重保存为无 pickle 的 NPZ，加载后使用不可写字节缓冲区。检查点绑定特征与
目标定义、权重、推断源码、势函数源码、跟踪配置和冻结上游身份。改变预算、
宽度、评分器或上游生产者时必须重新核对合同。数据库重开需提供同一优先级
模型；重复事件也不能绕过检查。

## 4. 运行与资源计量

各路径和哈希需使用实际封存产物，不提供虚构运行值。

1. `tools/event_track_v2x/collect_allocation_training.py`：生成 train 教师回放。
   可传冻结身份检查点；不传时明确为几何开发模式。
2. `tools/event_track_v2x/train_allocation_policy.py export`：凭回执 SHA256 导出
   特征／目标分片。
3. `tools/event_track_v2x/train_allocation_policy_ddp.py`：新增每个种子独立的四卡
   训练器，正式入口拒绝 CPU／V100 和小型测试数据。目标按选择点等权归约，
   可在不同机器上并行不同种子；ClearML 专用封装与真实全量训练仍待完成，见
   [四卡优先级训练记录](priority-ddp-training-20260913.md)。旧
   `train_allocation_policy.py fit` 保留作本地夹具测试，不用于此次用户要求的正式训练。
4. `tools/event_track_v2x/run_component_persistent_forest_v2.py`：增加
   `--allocation-checkpoint` 与 `--allocation-checkpoint-sha256` 启用学习分配。
   不传时仍是确定性分配；身份检查点与优先级检查点分别绑定。

教师的试算、缓存复制和 SQL 回滚属于离线成本，不计部署搜索预算。教师回放
的实测延迟包含试算成本，标记 `latency_includes_offline_teacher_probes=True`，
不得填入在线资源主表。部署的特征提取、解码和 MLP 推断计入实际回放耗时。

每事件最多 262144 个特征行；教师另限 1048576 个请求试算步骤。原搜索、缓存、
前沿、前缀、映射和状态重放容量继续生效，超限回滚整个事件。这些条目上限
不等于 RSS 或尾延迟上限，仍需真实资源曲线。

## 5. 已有证据与剩余工作

独立穷举检查学习排序下的遗漏质量及实际动作 regret；教师探测前后比较数据库
和共享缓存，并与原确定性轨迹比较输出。还检查试算异常后回滚与重试、未来
输入拒绝、同模型重开、旧输出幂等及模型变更拒绝。

三种子测试验证权重确实更新、CPU 重复拟合可复现，以及修改留出标签不影响
拟合权重。V2 测试接通「学习身份势 → 教师轨迹 → 优先级拟合 → 双学习模块
回放」，并与其他后端比较原始行势摘要。

回执见[学习分配验证记录](learned-allocation-validation-20260913.md)。仍缺真实全量
采集训练、全流程隔离、闭环泛化、纯恢复消融、经典强基线、同资源比较，以及
SPD 全 val 与 V2V4Real 冻结后的官方 test。所有新入口保持 `paper_eligible=False`。
