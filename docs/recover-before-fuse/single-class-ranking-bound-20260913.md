# 单身份类排序上界：推导与关闭现场诊断

目前完成了独立数学实现、关闭现场诊断和在线后端接入，在线集成回归 137 项通过。真实 train 回放仍在第 22 个决策事件因前沿容量耗尽失败，完成 21/195 个事件；随后在数据库副本上独立复现并保留异常现场，详见第 7 节。不能报告原容量问题已修复或跟踪性能获益。这个上界约束最大的单个身份类，不约束配分函数或遗漏质量。

## 1. 固定前缀的上界

节点按因果顺序编号为 \(0,\ldots,n-1\)。节点 \(i\) 选择新生或合法父节点 \(p<i\)，正势分别记为 \(b_i\) 和 \(\psi_{ip}\)。同一根配置可能对应多个父路径；身份类权重必须对这些路径求和。

假设合法性只依赖根配置，包括同一身份不能占据相同的源／帧位置。给定合法根配置 \(r\)，父选择的求和可按行分解：

\[
w(r)=\prod_i t_i(r),\qquad
t_i(r)=\begin{cases}
b_i,&r_i=i,\\
\sum_{p<i:r_p=r_i}\psi_{ip},&r_i<i.
\end{cases}
\]

不支持的边不进入求和。若增加依赖具体父路径的约束或高阶势，这个分解需重新证明，不能直接沿用。

固定深度为 \(d\) 的合法根前缀。令其精确类权重为 \(W_d\)。对未处理行 \(i\ge d\)，定义已知根组质量和未知父质量：

\[
B_i(g)=\sum_{p<d:r_p=g}\psi_{ip},\qquad
U_i=\sum_{d\le p<i}\psi_{ip}.
\]

任何完整后缀中，匹配到已知根的行至多得到某一组 \(B_i(g)\) 与全部未知父质量；匹配到新根的行至多得到 \(U_i\)。因而

\[
t_i(r)\le M_i(d):=\max\{b_i,\ U_i+\max_g B_i(g)\},
\qquad
\boxed{\max_{r:r_{<d}=r_{<d}^{\star}}w(r)
\le C_d:=W_d\prod_{i=d}^{n-1}M_i(d).}
\]

空组的最大质量为零。各行不一定能同时取得右侧最大值；这只会使上界更松，不影响有效性。忽略后缀的源／帧互斥也只会扩大可行域。

原行和松弛为

\[
P_d=W_d\prod_{i=d}^{n-1}\left(b_i+\sum_{p<i}\psi_{ip}\right).
\]

逐行有 \(M_i(d)\le b_i+\sum_p\psi_{ip}\)，所以精确算术下 \(C_d\le P_d\)。揭示下一个根后，未知父质量转移到至多一个已知根组，\(U_i+\max_gB_i(g)\) 不会增加；被处理行的真实转移质量也不超过原行上界。因此合法子前缀的上界不大于父前缀上界。完整深度下，上界回到该类的精确权重。

## 2. 尚未展开的旧分量组合

在选择旧保留类的笛卡尔积组合前，具体旧根尚未知。可用旧支持图的分量分组替代具体根分组，条件是每条旧支持边的两端均属于同一组。任一旧身份只能处于某个组内，因此以整组父质量替代具体根质量仍给出通用后缀上界。

诊断实现 `for_predecessor_partition` 检查不切断旧支持边，只返回后缀因子上界，不补造先验类权重。若排序游标独立提供未展开旧组合的最大权重上界，两者相乘可约束未展开组合的最大完整类权重。第 6 节的新在线后端已接入这一组合，旧后端不变。

## 3. 两个必须保留的反例

第一，逐边取最大值无效。若一个身份根通过两个父节点收到 0.6 和 0.7 的势，前缀质量为 0.9，则完整类质量为 \(0.9(0.6+0.7)=1.17\)。错误的逐边最大值只有 \(0.9\max(0.6,0.7)=0.63\)，低估真实类质量。

第二，最大类上界不是总质量上界。一个旧根和一个新节点，后者的新生、匹配势均为 1 时，最大身份类权重为 1，但两个合法类的总质量为 2。不能用 `log_single_class_upper` 替换跟踪器的配分函数上界，不能据此计算遗漏质量、校准概率或 regret 保证。

这些结论属于可容许松弛，不作为独立的新颖性主张。方法贡献仍需由恢复机制、计算分配和真实实验支持。

## 4. 实现及验证边界

`tools/event_track_v2x/ranked_class_bound.py` 使用 log 域计算，先对同根父路径求和。它校验因果边、有限势、正新生、规范根前缀、源／帧互斥和输入规模。返回值明确标记 `partition_mass_bound=false`、`formal_numeric_certificate=false`。浮点裕量不是定向区间算术，不能称为数值形式化证书。

该诊断实现逐次扫描前缀与后缀，报告输入因子项数；这些项数不是完整 CPU 指令、SQL 查询或在线工作预算。当前未声称常数开销，也未声称与现有在线内核资源公平。接入时还需要明确计入根查询、分组求和、缓存和组合游标的成本。

测试对 6 组随机六节点正势分别开启／关闭源帧互斥，独立枚举所有父路径，再汇总为完整身份类。对每个合法前缀验证精确类权重、最大完整类上界、原行和松弛及前缀细化单调性；另含上述反例、粗分组、极端 log 值和非法输入。只读现场入口另检验摘要、未关闭事务旁文件、前缀祖先损坏和源帧冲突。

## 6. 在线接入与验收
