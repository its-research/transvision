ROI 内仍有预测记录变化。因此本次差异不只发生在 ROI 外，但没有带来指标收益。
ROI 内预测增加 36 个，全部预测从 8,570 增至 8,625 个。辅助重复预测多余框数
从 210 增至 215，初始 ID 偏离段数从 73 增至 76；这些计数不能单独识别误差因果链。

开启组原始范围审计确认未用未来观测或位姿，也未改变原身份解码范围和权重。
它使用额外 51,276 步搜索、124 次状态更新，记录 143 次覆盖重建，但内部恢复事件
计数为 0。不能把额外搜索、覆盖重建或 ID 集合变化改称 GT 身份修复。
数据库分别为关闭组 428,625,920 B、开启组 534,077,440 B；推断时间分别为
1,055.968 s、2,320.127 s。运行共享 CPU 且未重复计时，不支持同延迟、同内存优势。

本结论只适用于 train 序列 `0004`、身份种子 1337 和该固定恢复预算；不是完整
方法失败的证明，也不是 validation、三种子统计检验或论文最终结果。
