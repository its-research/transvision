## 分量定义与精确分解

对决策时刻已到达的节点及固定候选支持，以所有候选父边构建无向连通分量
\(C_1,\ldots,C_m\)。分量划分不使用分支得分阈值，也不删除低权重候选边。
既有门控已排除的边仍在模型支持之外，其误差不包含在遗漏质量界中。

固定当前势函数 \(\theta\)。由于不同分量之间不存在身份父路径，一个身份的
同源同帧互斥约束完全位于某个分量内部。因此合法动作与假设集合均可分解为
笛卡尔积，而不只是 pair 分数可分解：

\[
\mathcal H=\prod_c\mathcal H_c,\qquad
w(h)=\prod_c w_c(h_c),\qquad
Z=\prod_c Z_c,\qquad q_\theta(h)=\prod_c q_c(h_c).
\]

每个合法整体森林在分量内的限制给出唯一局部森林；反过来，任意局部合法森林的
组合均合法。这一双射及可分权重证明了配分函数乘积关系。实现保留原始节点 ID，
只重排局部索引；输出根身份不会因局部重排而改名。

设每个分量的显式保留集合为 \(A_c\)，条件遗漏质量为 \(\eta_c\)，则

\[
\eta_{\rm product}=1-\prod_c(1-\eta_c)
\le 1-\prod_c(1-\bar\eta_c),\qquad
\log Z\le\sum_c\log Z_{U,c}.
\]

这里的整体保留集合是 \(\prod_c A_c\)。实现不显式生成这个集合；各分量保存
局部分支及前沿。局部分支的绝对 log weight 仅属于其分量，不冒充整体后验概率。

## 身份损失与共享预算

对非 anchor 节点的归一化根身份错误，令 \(n_c\) 为分量内计入损失的节点数，
\(N=\sum_c n_c\)，\(\lambda_c=n_c/N\)。当 \(N=0\) 时损失为 0。于是

\[
\ell(a,h)=\sum_c\lambda_c\ell_c(a_c,h_c),\qquad
\min_aR_q(a)=\sum_c\lambda_c\min_{a_c}R_{q_c}(a_c).
\]

第二式还依赖合法动作空间的笛卡尔积分解。若每个局部动作的条件优化差距为
\(\delta_c\)，则在精确数学下，完整有限窗口模型中的决策 regret 满足

\[
\operatorname{Regret}_q(a)
\le\sum_c\lambda_c\min\{1,\bar\eta_c+\delta_c\}.
\]

证明是逐分量应用遗漏质量分解，再按 \(\lambda_c\) 加权。它不要求显式枚举
整体保留集合。对于保持上次关联和新节点 unmatched 的回退动作，没有上述局部
最优性前提；实现只给该分量平凡上界 1，并在审计中标记，不复用较小的解码界。

前沿展开优先选择 \(\lambda_c\bar\eta_c\) 较大的分量。动作搜索另按加权优化差距
分配预算。两种展开预算均为全场景共享，前沿和已发现叶子的存储也有共享上限。
这个调度是确定性启发式，不是学习式优先级，也没有声称单步风险降低量最优。
展开次数不能代替相同延迟或相同内存的实测对照。

以上结论约束固定势下的模型内风险。浮点数值是上界估计，不是区间算术证书；
真实后验误差、模型校准误差和 HOTA／IDF1 不由这些公式保证。

## 分量连接与前沿压缩

无连接变化的分量沿用原始支持和可恢复前沿。新节点同时连接多个旧分量时，
新分量从全部原始局部因子重建，不只组合旧 Top-K。重建后的前沿仍覆盖所有
合法身份历史，旧分量回执及其显式分支配置保持不可变。

追加节点若使旧前沿加显式叶子超过分量容量，可将当前推断退回覆盖完整支持的根
区域。此操作不平均连续状态，也不永久删除身份配置；它丢失的是已投入的枚举
工作，重新展开需要重新计费。审计分别记录 `merge` 和 `append_frontier_pressure`
重启原因、前驱提交及恢复的旧身份前缀。

回退保持原输出身份，新检测暂按 unmatched 处理。每个局部分支独立进行状态重放，
最终选择的整体动作再生成当前输出；历史输出不可回写。推断和状态重放全部成功
后才提交。事务副本只复制可变前沿、集合及映射，共享不可变因子和历史回执，
不为每次局部展开复制整段历史或新增一个提交。

节点、分量或共享存储仍可能真正超限。实现此时明确失败，不裁掉候选边、不删
观测来制造容量通过。这尚不是完整序列的资源不足处理方案。

## 神经网络上下文与受控对照

分量化概率推断的等价性只针对固定势。分别运行上下文神经网络通常不等于在全场景
运行同一网络。配置中的 `potential_context` 明确区分 `global`、`component` 和
随推断模式选择的 `auto`。

用于受控比较时，应显式固定 `potential_context='component'`，让分量推断与整体
森林推断使用逐项相同的势。已有测试验证了这一条件及穷举小场景的相同 3D 输出。
当前整体森林后端仍保留可恢复前沿，不是已经完成的不可恢复 Top-K 或经典 MHT
复现；这些基线及其同资源实验仍待实现。

例如，以下配置启用局部分量推断，同时将全场景节点限额与分量限额分开：

```python
ForestTrackingConfig(
    component_mode=True,
    potential_context='component',
    max_nodes=4096,
    max_component_nodes=128,
)
```

这些是工程配置示例，不是 train 选择完成的论文参数。默认恢复窗口仍为 2 秒，
不是跨窗口身份延续的替代品。
