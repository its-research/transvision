`forest_tracking.py` 已连接 `DetectionCacheV2`、联合身份森林、独立分支的 3D 状态
重放与现有预测评价格式。`forest_potentials.py` 提供学习式跨端／时序评分和几何基线。
当前交付是单个有限窗口的可运行实现，不是完成训练和双数据集验证的论文方法。

2026-09-13 已接入[可恢复分量推断](forest-components.md)，支持共享预算、分量连接
后的原始因子重建和前沿压力下的可恢复压缩。完整序列窗口交接仍未完成。

同日新增[边界状态交接和身份权重参照](forest-boundary.md)：可从存档重建原 active
之外的合法历史，并用完整枚举验证按根配置汇总权重。这是边界基础与小场景参照，
没有将有限窗口跟踪器改为有界内存的完整序列方法。

随后新增独立的[持久化长序列后端](persistent-forest.md)，已验证跨窗口 ID 延续和
V2 接收事务，但没有替换此处的 `CausalForestTracker`，也没有完成真实训练与评估。

## 数据与因果边界

缓存适配器仅选择 car，按固定 raw score 阈值与数量限额选取观测。检测框转换为
物理世界坐标。状态时刻、图像信息时刻与实际到达时刻分别保存；未到达的数据在
读取特征之前被拒绝。每个原始观测与缓存哈希绑定，不接受 GT 字段。

`forest_cache_stream.py` 现已验证完整 V2 输入范围、来源和特征 checkpoint 的一致性。
其接收层在加载新帧前检查到达条件，重复传输保留首次到达时刻，不重复计入检测。
推断成功后才提交接收记录；失败可重试，旧事件保持幂等。完整缓存哈希审计是离线
输入校验，不等于未来帧特征已进入推断。每次实际加载仍重新校验文件哈希。

新特征标识为 `recover-before-fuse-physical-world-cache203-v1`。虽然维度仍为 203，
几何和时间分量已不同于旧模型；不能直接把旧 203 维 checkpoint 声称为本方法。
冻结视觉向量保持原值，新增身份网络仍须训练。

候选支持由已到达观测的运动距离、时间间隔和邻居数确定。旧行支持不会在重评分
时被删除。质量界只覆盖这个支持内的有限模型，不包含门控排除正确关联的误差。

## 状态与输出

每个显式身份分支从不可变原始检测独立重放。迟到观测按状态时间插入重放，
不能由已平均的兄弟分支状态重建身份。连续更新采用 CI 工程估计，不声称等于
精确贝叶斯轨迹后验。新生及存活分数独立于关联权重。

动作搜索在全部合法森林中进行。若已报告的模型内风险估计不超过配置阈值，输出
相应动作；否则保持上次输出关联，新到观测先按 unmatched 输出。该回退动作不写入
后验。分支仍保留，后续证据可改变当前及未来输出，不改写旧输出。

旁路审计保存绝对分支权重、父分支、原始局部势、未展开质量上界估计、恢复事件、
输出与审计提交链。新节点到达后恢复的旧身份前缀单独记为
`restored_ancestral_prefixes`，不把普通节点扩展计作恢复。

节点、前沿、发现叶子、重放操作和提交数均有限额。推断与重放成功后才提交状态；
超限或失败不会发布部分结果。重复事件返回原回执，冲突内容被拒绝。

- 学习式展开优先级，以及同延迟、内存预算下的 Top-K、MHT、JPDA/PKF 比较。
- SPD 与 V2V4Real 的真实验证、恢复事件解释、校准误差、尾延迟与内存统计。

窗口过期目前明确失败，不会以单 MAP 交接冒充完整后验延续。浮点质量界不是数值
区间证书，模型内风险也不是 HOTA、IDF1 或真实后验的保证。
