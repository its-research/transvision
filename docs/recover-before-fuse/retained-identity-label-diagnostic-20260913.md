# 保留身份候选的局部标签诊断

完整 train 序列 `0000` 的两组诊断均完成 195 个事件。对新到达行只计一次时，逐节点
beam 的局部关系误差为 3.2877%，事件完整 Top-4 为 7.8847%。即使事后在后者每个
已保存的保留集中选择局部标签误差最低的类，也仍为 7.6365%。这些数值不是 HOTA、
IDF1 或完整身份错误率；它们说明当前负结果不只是末端从既有四个候选中选错一项。

最早分歧事件提供了另一类直接证据：更低局部误差的类仍在 Top-4 中，但其模型权重
较低、没有被选中。因此，不能把这个事件的差异解释为正确身份候选已被删除。

## 2. 有界、对根编号不敏感的局部损失

令 \(P_i\) 为观测 \(i\) 的已知父候选关系集合，不包含 birth 选项。对
\(j\in P_i\)，标签 \(y_{ij}\in\{0,1\}\) 表示二者是否属于同一标注身份。
只有 \(|P_i|>0\) 的行参加统计。对完整合法身份类 \(H\)，令 \(r_i(H)\) 为根编号，定义

\[
e_i(H)=\frac{1}{|P_i|}\sum_{j\in P_i}
 \mathbf1\!\left\{\mathbf1[r_i(H)=r_j(H)]\ne y_{ij}\right\}.
\]

每一项均为 0 或 1，故 \(0\le e_i(H)\le1\)。统一重命名身份根不会改变根相等关系，
所以损失不依赖任意根编号。对当前统计范围 \(S\)，取

\[
E_S(H)=|S|^{-1}\sum_{i\in S}e_i(H).
\]

它是等行权重，不是等边权重。例如，两行分别有 1 和 3 条已知关系，只有第一行出错，
则等行误差为 \(1/2\)，等边误差为 \(1/4\)。冻结协议最多 8 个父候选，因此实现使用
\(\mathrm{lcm}(1,\ldots,8)=840\) 个整数单位表示每行误差，候选优劣比较不靠浮点容差。
无已知关系的统计范围输出 `null`，不能冒充零误差。

主统计 `new_rows_only` 只统计本事件新到达、且属于原决策范围的行，避免同一历史行
重复计数。辅统计 `decision_scope` 沿用全部原决策范围；其中同一行会跨多个事件出现，
不当作独立样本。本轮主统计包含 4,230 行、33,636 条已知关系；两组逐事件范围和
分母均已核对一致。4,245 个训练监督行中有 15 个 birth-only 行没有可评估父关系。

## 3. 保留集与选择误差的分离

令 \(K_c\) 为分量 \(c\) 已保存的活动身份类集合，\(a_c\) 为实际输出类。
如果输出类在活动集合之外，诊断候选域扩展为 \(D_c=K_c\cup\{a_c\}\)，但不把它
擅自加入活动集合的归一化概率。对同一个固定候选域，有恒等式

\[
E(a)=\min_{h\in D}E(h)
 +\left[E(a)-\min_{h\in D}E(h)\right],
\qquad E(a)-\min_{h\in D}E(h)\ge0.
\]

已知关系边的父节点都属于同一歧义分量，损失对分量可加。因此，固定各分量的
候选集合后，在笛卡尔积中求最优可分解成各分量独立求最小值，不必枚举全部组合。
它是使用事后标签得到的固定候选集最优值，不是实际可用的无标签解码器。

最优值大于零，只证明当前候选域没有局部标签完全相容的类。它不能证明完整模型
中存在零误差类，更不能证明这个类曾经保留、后来被删除。门控、未知标签、标注匹配
误差和全局一致性均可能影响这一判断。原解码器使用的根标签风险与本文关系损失不同，
不能把原审计的模型风险上界直接套用到本文的局部误差。

一个可穷举反例是：前两个观测因门控只能各自新生，第三个观测可新生或连接其中
任意一个；两个父关系的标签均为同身份。合法父配置只有 `(-1,-1,-1)`、
`(-1,-1,0)`、`(-1,-1,1)`。第三行的局部误差分别为 1、1/2、1/2，即使全部保留，
最优误差仍为 1/2。单父森林不能用第三个节点合并两个既定历史根。这个反例证明
「没有零误差候选」不等于「截断删除了正确候选」；尚未声称它解释了真实序列中的全部失败。

此外，这个最优值仅约束已经保存的候选集。若真正改变逐帧解码策略，后续候选集也
可能改变；本诊断不是新时序策略的性能上限。

## 4. 条件概率诊断

对活动集合 \(K\)，使用独立重算的绝对类权重 \(w(h)\)，定义

\[
q_K(h)=\frac{w(h)}{\sum_{g\in K}w(g)},\qquad
p^K_{ij}=\sum_{h\in K}q_K(h)\mathbf1[r_i(h)=r_j(h)].
\]

类权重对表示同一身份配置的全部父路径求和，不是仅取规范代表路径。
随机小图的独立完整父路径穷举已验证这一计算。真实前缀重算与保存权重按绝对
容差 `1e-9`、相对容差 `1e-12` 核对；这不是形式化浮点证书。

报告已知关系边等权的 Brier 分数，以及固定 10 个等宽概率区间的 ECE。
区间按 \(\min(9,\lfloor10p\rfloor)\) 分配；只修正不超过 `1e-12` 的概率舍入越界，
没有拟合平滑参数。所有概率仅以保留集为条件，没有计入遗漏质量，也不是完整真实
后验。ECE 不能当作理论中模型与真实后验的 TV 误差 \(\zeta\)。

## 8. 恢复开启对照：局部误差与原生指标方向不同

恢复开启运行随后也完成了全部 195 个事件的同协议诊断：同样是 7,350 条原始观测、
4,230 个首次出现的可评估行和 33,636 条已知关系，前缀检查数为 3,143,514。
它的新行局部误差为 `0.0327296521`，略低于恢复关闭的 `0.0328774063`；条件
Brier 也由 `0.0322999708` 降为 `0.0321646955`。

但回查已封存原生结果，HOTA 从 `0.3999513607` 降为 `0.3997447039`，IDF1 从
`0.5252002465` 降为 `0.5244608749`。本轮没有重算或改写原生指标。两个原生指标文件
的 SHA-256 分别为 `8cfd7324cebb7a1cfaacec4af35ecf696240bfc57081a69f85dc2af1cccd8ea3`
与 `4e4b240289c6b33371e975a7fc26d3cf7f034b607ed69f80d14d8c9abda756f0`。

这个方向差异是同一序列上的实际观察，不是统计显著性结论。局部关系标签不覆盖全部
身份对、目标存在、ROI 内轨迹完整性或原生匹配过程，不能据它的轻微改善宣称恢复有效。
三个诊断运行仍对应同一个 train 序列，不构成三种子或三个独立序列验证。
