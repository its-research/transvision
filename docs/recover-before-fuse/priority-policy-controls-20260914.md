# 优先级模型：固定对照与一步选择评估

`evaluate_priority_policy_controls.py` 已实现离线评估接口，用于检查学习器是否
仅降低回归误差，还是改善了候选选择。当前没有完成的优先级模型三种子训练，
因此还没有真实模型评估结果。身份模型检查点不能作为优先级模型输入。

该工具不训练、不筛选样本、不重放跟踪。只使用完整 train 教师导出的 18 维
数值特征和一步模型目标；不读取 GT、SPD val/test 或 V2V4Real test。
它不能替代同资源跟踪实验、教师行为等价审计或完整来源审计。

## 固定对照

每个候选组保留原导出顺序。所有方法在完全相等的最高分间选择第一个候选。

| 方法 | 用于选择的分数 | 报告目标 MSE |
| --- | --- | --- |
| 零预测器 | 所有候选均为 0 | 是 |
| `weighted_eta` 特征规则 | 分配权重乘以遗漏质量上界 | 否 |
| 学习模型 | 冻结优先级网络输出，三个种子分别报告 | 是 |

特征规则是可从数值分片复算的固定对照，不自动等于教师实际执行行为。导出分片
不含候选分量 ID 或已选操作，因此报告保留
`feature_rule_is_recorded_behavior_verified=false`。实际行为比较仍需完整教师记录。
`weighted_eta` 不是一步目标预测值，不能将其数值直接纳入目标回归 MSE 比较。

序列留出严格复用训练器的 `priority-holdout-v1` 哈希划分。主结果使用
`train_sequence_holdout`；拟合序列结果单列。双方均报告全部候选组与逐序列结果。
三种子必须齐全、配置一致；不选最好种子、最好 epoch 或更有利的子集。

## 指标与数学边界

设一组有 \(m_g\) 个候选，教师目标为 \(y_{gi}\in[-1,1]\)，冻结预测为
\(f_{gi}\)，方法选择 \(a_g=\arg\max_i f_{gi}\)。回归误差按组等权：

\[
E_g=\frac1{m_g}\sum_i(f_{gi}-y_{gi})^2,\qquad
\widehat L=\frac1G\sum_g E_g.
\]

一步模型进展缺口为

\[
D_g=\max_i y_{gi}-y_{g a_g}\in[0,2].
\]

它不是论文中的真实身份决策 regret，也不是长期计算收益或 HOTA 损失。
改变选择会改变后续候选、状态和预算，不能把各组教师目标当作同一条新轨迹的
可实现累计收益。

对 \(a_g^*=\arg\max_i y_{gi}\)，若两个选择不同，由预测最优性及
Cauchy–Schwarz 不等式，令 \(e_i=f_{gi}-y_{gi}\)，有

\[
D_g\le e_{a_g}-e_{a_g^*}
\le\sqrt{2}\lVert e\rVert_2
=\sqrt{2m_gE_g}.
\]

若选择相同，缺口为 0。因此 \(D_g\le\min\{2,\sqrt{2m_gE_g}\}\)。这是
固定候选组的基础误差关系，不是方法创新。候选数较多时界可能很松，也不证明
误差下降会让离散选择改善。

反例：\(y=(0.09,0.10)\)，\(f=(0.0951,0.0949)\)。模型 MSE 为
`0.00002601`，小于零预测器的 `0.00905`，却仍选择较差候选，一步缺口为 `0.01`。
因此同时报告选择目标均值、缺口均值、相对特征规则的目标差，以及胜／平／负计数。

全部组都进入主结果。另报告候选数至少为 2、目标极差大于 `1e-12` 的描述性子集，
不改变训练或主评价样本。先根据特征确定选择，再使用标签计算指标和分组。
没有符合条件的组时均值为 `null`，不伪造为零收益。

## 输入检查与使用

正式 CLI 要求完整 46 序列 train 导出和三个完成的四卡或更多 A100 DDP 回执。
它检查固定划分、来源摘要、配置、全部 epoch、rank 样本覆盖与损失求和，加载
原始权重并复算最终 holdout MSE。最终拟合序列 MSE 不等于训练日志中沿优化过程
累积的 online training loss，因此不会错误地要求两者相等。

这些检查证明保存文件之间一致，不独立证明 GPU 执行、远端任务状态或原始教师
轨迹的真实性。`remote_execution_attested` 与 `teacher_trace_reaudited` 仍为
`false`。训练及教师原始审计需要另外提供，不能靠更改清单标志补齐。

在 transvision 根目录运行下列命令。占位符需要替换为实际文件和独立保存的摘要；
输出父目录必须存在，输出文件必须不存在。

```bash
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  /private/tmp/eventtrack-v2-checks.bYZm1l/bin/python \
  tools/event_track_v2x/evaluate_priority_policy_controls.py \
  --data <完整优先级训练导出目录> \
  --manifest-sha256 <导出清单摘要> \
  --run <种子1337训练输出根目录> <receipt.json摘要> \
  --run <种子2027训练输出根目录> <receipt.json摘要> \
  --run <种子3407训练输出根目录> <receipt.json摘要> \
  --output <新的本地评估文件.json>
```

任一输入缺失、摘要变化、种子缺失、训练边界不符或复算误差超出容差时，工具
拒绝生成正式报告。保留原始文件并检查失败原因，不覆盖检查点、不放宽划分或
删除失败种子。CLI 没有 fixture 放行选项；低层软件测试明确标记模拟数据。

与此工具对应的测试为 `tests/event_track_v2x/test_priority_policy_controls.py`。
测试使用静态权重、手算组和模拟回执，不执行参数拟合。工具实现、软件测试通过、
真实训练完成和原生跟踪收益是四种不同状态。
