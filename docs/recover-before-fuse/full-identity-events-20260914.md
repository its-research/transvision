# 完整 SPD val 的可观测身份事件诊断

新增 `tools/event_track_v2x/evaluate_full_identity_events.py`，将已有单序列身份事件
定义用于完整 SPD val。种子 1337、2027 的六个运行均完成诊断，各覆盖 21 序列、
3,316 帧。种子 3407 的三个诊断已启动，尚未计入本节完成数。

这是一项旁路评价，不修改 DetectionCacheV2、预测、历史 ID、推断源码或模型。
它不是官方 IDS、真实身份错误率、完整错误持续时间或方法恢复收益的证明。
原生主指标和实际身份历史审计见 [JPDA／PKF 完整验证](spd-probabilistic-full-val-20260914.md)。

## 1. 输入与定义

入口先验证完整推断回执及对应的独立审计，再读取冻结 GT。它接受 `probabilistic`
和 `scan-mht` 两种已审计后端；本节真实完成数据只有前一种。GT、预测和逐帧审计
必须在序列、帧、时刻及提交链上对应，分序列计算后汇总，不跨序列继承身份锚点。

- 仅评价 car，沿用严格 XY 距离小于 50 m 的 ROI，SPD 类别映射保持不变。
- 在 BEV IoU 不小于 0.5 的二部图中，只接受两侧度均为 1 的唯一匹配。
  缺失、重复或歧义匹配均保留为未判定，不强制通过 Hungarian 分配 GT。
- 每个序列、GT 身份第一次严格唯一匹配到的预测 ID 作为固定锚点。
  后续不同 ID 计为「锚点偏离」；首个锚点可能已经错误，绝对正确性不可由此判定。
- 未判定、GT 离开 ROI／缺失、序列结束会截断当前片段；未知间隔后再次偏离的
  起点也被标记为受截断影响。只有再次观测到原锚点时，才记录「观测到返回」。
- 观测跨度为 `(last_wrong_us - first_wrong_us) / 1e6`，不能当作连续错误总时长。
  内部恢复记录、数学上界和 GT 身份诊断分别报告；未记录不等于数值为零。

`summary.json` 保留未判定分母、左右截断计数及全部输入摘要；
`identity-events.json` 保留逐帧计数和片段。时长分位数从全部原始片段跨度合并计算，
不是序列分位数的平均值。全部 GT、事件明细及完整预测留在私有临时目录，不新上传。

## 3. 验证范围

最终入口及测试的 23 项检查通过，JUnit 记录耗时 0.436 s。测试包括序列锚点隔离、
未知／重复匹配、全未知场景、空输入、缺帧、时刻和提交链错误、完整审计前置条件、
合并分位数及评价进程不加载 Torch。小场景测试不代表真实数据集效果。

对上述六份真实报告另行执行独立计算：从逐帧记录复算唯一、未判定、偏离和重复
GT 帧计数；从片段记录复算观测数、左右截断和原始微秒跨度；使用排序加线性插值
复算四个分位数，与输出的最大绝对误差为 0。重新检查 288 个去重输入文件及
六组输出载荷摘要，均一致。本次独立复算未重建几何匹配图、GT 锚点分配和重复
预测的超额计数，不扩大为全部诊断算法的独立复现。
