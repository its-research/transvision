# 可恢复窗口边界：状态交接与身份权重参照

2026-09-13 已实现可恢复边界存档、任意合法历史的条件状态重建，以及小场景的完整
身份权重边缘化参照。代码位于 `transvision/models/event_track_v2x/forest_boundary.py`
和 `forest_boundary_prior.py`。这两项实现没有完成有界内存的长序列推断，也没有产生
新方法的真实数据集跟踪指标。

后续已增加[持久化长序列后端](persistent-forest.md)，通过共享前缀与磁盘原始历史
避免在时间边界做单 MAP 交接，并接入 V2 接收和几何开发运行入口。该后端与本文的
完整根边缘化参照是不同实现；它尚未接入分量分配、新模型训练和真实全序列验证。

`CausalForestTracker` 仍按有限窗口运行，窗口过期会明确失败。边界存档保留全部旧
原始观测和因子，不会把保存成功解释为已释放全部历史内存。精确参照会枚举所有旧
历史及分量身份配置的组合；超过预算时失败，不返回被重新归一化的 Top-K 替代品。

## 1. 边界存档保存什么

`checkpoint_tracker` 只接受已有不可变输出的 `CausalForestTracker`。它核对当前原始
观测、局部因子、推断快照和配置与最后一次输出审计是否一致，然后生成存档。
该操作不选择 MAP，不修改跟踪器，也不改写历史预测。

存档包括原始观测、原始候选支持及绝对势、完整的可恢复前缀覆盖、已发现历史、
原输出身份动作、配置和来源哈希。分量模式逐分量保存，不展开显式分支的全局组合。
`source_cache_manifest_sha256` 仅保存调用方提供的来源标识，不等于独立验证了缓存
全集。哈希用于内容完整性和引用绑定，不是来源签名、概率校准或推断正确性的证明。

保存使用独占创建，不覆盖已有文件；读取拒绝未知字段、非规范 JSON、哈希不符、
软链接路径和超出字节上限的文件。`save` 返回的是规范载荷的存档提交哈希；
`load(expected_archive_sha256=...)` 要求这个值，不能传入整个文件的 SHA256。

`project(parents)` 可以重建任何原支持内的合法完整历史，不限于原 Top-K 或已枚举
历史。每个身份根保存独立的连续状态、原始观测成员、已占用源帧、分数时刻见证和
稳定 ID。不同根配置之间不做矩匹配。恢复标记区分「原 active 之外」和「此前从未
枚举」，不能把普通扩展或已发现分支重新激活都计成首次恢复。

边界以信息时刻选出保留观测集合 $S$。当前完整身份参照使用全部旧节点的根向量，
而不只使用 $S$ 上的根标签。即使两个历史的 $S$ 标签相同，过期身份及其状态仍可能
不同；例如 $S$ 为空时，一个历史可能只有一个身份，另一个历史有两个身份。因此，
当前参照不能被称为已完成最小分隔变量上的身份先验压缩。

## 2. 为什么不能把所有分支先推进到窗口边界

设固定身份历史为 $h$，按 `(state_us, source_id, node_id)` 排序的观测为
$o_1,\ldots,o_m$。当前工程状态更新是运动传播与固定权重 CI 的确定性组合，
记为 $z_i=U(z_{i-1},o_i)$。这里不声称 CI 等于精确贝叶斯轨迹后验。

对同一个 $h$，若后续待处理观测全部排在旧观测之后，则直接从 $z_m$ 继续更新，
与从 $o_1$ 开始执行同一串更新完全相同。这个结论只使用函数组合，没有额外的
独立性假设；保存的 $z_m$ 必须仍处于最后一次实际观测时刻。

当前运动传播使用 $F(t)$ 和 $Q(t)=\rho |t|I$。对正时间 $s,t$，

\[
Q(t+s)=\rho(t+s)I,\qquad
F(s)Q(t)F(s)^\top+Q(s)=\rho tF(s)F(s)^\top+\rho sI.
\]

两者一般不相等。因此，先传播到任意切分时刻再继续传播，会额外改变协方差；
不能以运动矩阵满足 $F(s)F(t)=F(s+t)$ 为由推断噪声也满足同样的组合性质。

`BoundaryCarry` 保留最后一次原始观测时刻的状态。`replay` 仅在所有待处理观测的
排序键都晚于该时刻时继续使用它。若旧保留观测或新到迟到证据插入了已压缩的
时间顺序，则从该身份的全部原始观测重放。输出时刻的最后一次传播只执行一次。

身份恢复后必须重新投影所选历史，不能借用旧输出分支的状态。新生、存活分数和
年龄取自原始检测及真实状态时刻，不乘关联质量，也不在切分时刻重置。
当前实现会重新验证并重建调用方提供的投影，因此没有把投影复用声称为已获得的
延迟收益。审计同时记录投影构建工作量和后续重放工作量。

## 3. 完整身份权重的边缘化

令旧窗口合法父指针历史集合为 $\mathcal H$，正权重为

\[
w(h)=\prod_{i=1}^{n}\psi_i(h_i),\qquad r(h)=(r_1,\ldots,r_n).
\]

$r(h)$ 是全部旧节点的身份根向量。不同父指针路径可能得到相同 $r$，因此其
身份配置权重应为

\[
\boxed{W(r)=\sum_{h\in\mathcal H:r(h)=r}w(h).}
\]

不能将求和替换为最大值，也不能把每个不同根向量都当作等权候选。一个最小示例
是三个连续节点、所有允许势均为 1：六条合法父指针历史对应五个根向量，其中
`(0,0,0)` 对应两条历史，其概率为 $2/6$，而不是 $1/5$。

设后续父指针选择为 $e$。以下条件同时成立时，完整根向量是这一步扩展的充分表示：

- 原始节点、旧候选支持和旧行权重已经固定。
- 新行势针对共同的原始节点索引定义，不依赖旧历史的具体父指针拓扑。
- 合法性只依赖共同候选支持、父指针先后关系和根内源帧排除约束。
- 条件状态由同一根内的原始观测成员及其固定更新顺序确定。
- 所分析的身份损失只依赖根向量，而不是父指针历史本身。

同一 $r$ 内的历史有相同身份成员和已占用源帧；对任意相同 $e$，新节点的根及
合法性也相同。于是

\[
T(e;r)=\mathbf1\{(r,e)\text{ 合法}\}
       \prod_{i=n+1}^{n+m}\psi_i(e_i),
\]

\[
\begin{aligned}
\sum_{h:r(h)=r}w(h)T(e;r)&=W(r)T(e;r),\\
Z_+&=\sum_r W(r)\sum_e T(e;r).
\end{aligned}
\]

因此，先按根向量边缘化再扩展，与直接枚举全部新旧父指针历史得到相同的根后验，
并在相同合法动作集合上得到相同的归一化根身份损失风险。代表父指针仅用于索引
原始成员和状态重放，不能用它自己的单条权重替换 $W(r)$。

`marginalize_boundary` 从全部原始支持重建 $W(r)$，不读取 active 子集作为完整先验。
它先精确分解独立支持分量，再逐分量枚举。`extend_boundary_prior` 在预算允许时
枚举分量根配置的组合，支持新观测连接旧分量，之后再次按完整根向量汇总权重。
一旦旧行重评分，必须重新构造先验；不能继续使用旧的标量 $W(r)$。

这些是有限因子模型内的精确代数结论，浮点输出只是数值近似。若学习模块依赖
父指针路径本身，或只保留局部分隔标签而丢失其他必要状态，上述充分性不再成立。
工程上仍需实现可恢复的分隔变量搜索，才能避免完整枚举及全历史常驻。

## 4. 不要按每个旧身份分支分别归一化未来证据

记 $U(r)=\sum_e T(e;r)$。正确的新根质量与 $W(r)U(r)$ 成正比。如果先把每个身份
分支的未来因子除以自身 $U(r)$，再用旧 $W(r)$ 混合，便消除了区分旧身份的证据。
对所有历史都相同的公共行归一化常数不产生这个问题；分支特有的归一化常数会产生。

实现提供一个受源帧互斥约束驱动的反例。旧窗口包含「两条观测属于同一身份」与
「属于不同身份」两类假设，后者只占 $\eta=0.001$。新到的同一源帧中有两个不同
检测，各自倾向连接一个旧观测。匹配势为 1，新生势为 $\varepsilon=5\times10^{-7}$。

在旧合并假设下，新检测不能同时匹配该身份；在旧分离假设下可以同时匹配。因此

\[
u=\varepsilon^2+2\varepsilon,\quad v=(1+\varepsilon)^2,\quad
\eta_+=\frac{\eta v}{(1-\eta)u+\eta v}.
\]

这里 $u,v$ 是所声明模型的未来因子质量，不称为已校准的真实观测似然。独立数值
参照得到 $\eta_+=0.9990019977527468$。在相同完整合法动作集合上，永久截断旧
分离分支后再求 Bayes 动作，归一化根身份损失的 regret 为
$0.7488767478775283\le\eta_+$。恢复旧 active 之外的历史后，条件状态重放与完整
原始重放一致，原输出字节保持不变。

这个例子验证未来质量放大和截断风险机制，不证明真实交通数据存在同样的频率、
幅度或总体收益，也不把这里的身份损失等同于 HOTA 或 IDF1。
