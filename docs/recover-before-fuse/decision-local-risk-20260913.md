# 当前动作风险：区分历史截断与决策歧义

本轮确认两项不同的问题。前沿容量判断存在可安全放宽的保守条件，但解除该条件并未改善真实大分量的风险界。更根本地，即使配分上界精确，保留少数完整历史的质量也可能随历史歧义指数下降，而当前动作已经是模型内 Bayes 最优。

因此，后续推断需要区分「保存哪些可恢复历史」与「如何评价当前动作」。本文记录反例、一个不依赖显式历史质量的补充界、有限模型验证及真实状态诊断。补充界尚未接管在线解码，不能据此宣称完整方法、实时资源预算或真实跟踪收益已经成立。

## 1. 容量判断的修正与边界

原完整类候选统一预留一个前沿槽位，以容纳被移出的显式类。设显式类为 $A$，前沿区域并集为 $D(F)$。若

\[
A\subseteq D(F),
\]

被移出的显式类仍由现有前沿覆盖，不会新增区域。任意新合法完整类也在 $D(F)$ 内，因为原覆盖不变量为 $A\cup D(F)=\mathcal H$。此时插入后再选择显式 Top-K，前沿只可能保持或缩小。可采用

\[
r_F=\begin{cases}0,&A\subseteq D(F),\\1,&\text{其他情况},\end{cases}
\]

作为保守额外容量需求。这里依赖完整合法支持覆盖；不能用于已剪枝且丢失支持的结构，也不能替代前缀容量和实际后缀计算预算。

`covered_proposal_capacity.py` 实现该判断。`covered_completion_tracking.py` 提供独立的确定性、教师和学习分配原型，使用 `PersistentCoveredCompletionConfig` 与独立数据库 schema，保留原保守变体。实际执行后再次检查局部／全局前沿容量，超限回滚，不改变质量公式、源时刻、势函数或旧输出。

## 2. 完整历史质量趋近零，但当前动作并不模糊

构造一个连通的星形父森林。节点 0 必须新生；$m$ 个旧节点分别以相同势选择新生或连接节点 0。当前节点 $m+1$ 的新生势为 $\rho\in(0,1)$，连接节点 0 的势为 1。所有节点的源／帧槽位不同，因此不存在身份互斥冲突，全部父配置合法。支持图仍是一个连通分量，不能靠普通连通分量分解消除本例。

配分函数和当前根边缘概率可精确得到：

\[
Z=2^m(1+\rho),\qquad
q(R_{m+1}=0)=\frac1{1+\rho},\qquad
q(R_{m+1}=m+1)=\frac\rho{1+\rho}.
\]

损失只作用于当前节点。选择根 0 的动作对完整模型是 Bayes 最优；完整合法动作集合中，其 regret 为 0。对任意 $K\le2^m$，精确 Top-K 全部来自连接根 0 的历史，但每条完整历史的权重仅为 1，所以

\[
\eta=1-\frac{K}{2^m(1+\rho)}\longrightarrow1.
\]

本例没有配分松弛误差。它说明 $\eta$ 是合法但可能无用的当前动作 regret 上界，不说明原概率不等式错误。当前实际误差仍为 $\rho/(1+\rho)>0$；零 regret 不等于零错误。

取 $\rho=0.001$、$K=4$，有限模型诊断得到：

| 历史歧义位 $m$ | 完整历史遗漏质量 | 当前最优候选的精确模型 regret |
|---:|---:|---:|
| 4 | 0.7502497502 | 0 |
| 12 | 0.9990244131 | 0 |
| 24 | 0.9999997618 | 0 |
| 32 | 0.9999999991 | 0 |

原 0.05 风险阈值会拒绝这些候选并选择当前节点新生。该回退动作的模型 regret 为 $(1-\rho)/(1+\rho)\approx0.998002$。这是本反例中的解码行为，不是对真实数据误差率的估计。诊断直接插入精确 Top-K 来隔离界的行为；没有将插入成本冒充为在线搜索性能。

`diagnose_history_truncation.py` 使用实际类权重与解码器核对上述闭式结果。小规模部分另用完整父配置穷举验证；大规模使用解析参照，不声称穷举了数十亿历史。所有探测写入均回滚，不改写初始输出。首版结果 `history-truncation-counterexample-v1/counterexample.json` 的 SHA-256 为 `cce2a9f9f147c653a950254d2b84b6c9ab5f60d243141184e24a257d68ab4ebb`，位于同一诊断根目录。

这不授权把具有相同当前动作的旧历史永久合并：后续观测可能区分它们，连续状态也可能不同。原始因子、历史约束和可恢复分支仍须保存。

## 3. 不依赖显式历史质量的补充模型界

固定当前已到达信息下的正父势。令每行归一化概率为 $s_{ip}$，$p=-1$ 表示新生。先忽略同源同帧互斥，定义独立父选择模型

\[
q_0(h)=\prod_i s_{i,h_i}.
\]

令 $C$ 为全部身份互斥均满足的事件，$\delta=q_0(C^c)$。原固定因子模型恰为

\[
q(h)=q_0(h\mid C),\qquad q_0=(1-\delta)q+\delta r.
\]

全新生配置合法且势为正，因此精确算术下 $\delta<1$。若计算得到的上界达到 1，仍必须承认该界无信息，不能除以接近零的未证明合法质量。

### 3.1 根边缘与冲突概率消息

父选择按节点索引构成 DAG。定义 $M_{ir}=q_0(R_i=r)$，则

\[
M_{ir}=s_{i,-1}\mathbf1\{r=i\}+\sum_{p\ge0}s_{ip}M_{pr}.
\]

再令 $E_{ij}=q_0(R_i=R_j)$。对 $i>j$，节点 $i$ 新生不可能与旧节点 $j$ 同根，而其父选择独立于此前各行，因此

\[
E_{ij}=\sum_{p\ge0}s_{ip}E_{pj},\qquad E_{ii}=1,\qquad E_{ji}=E_{ij}.
\]

这一步使用联合根相等消息，不能用两个根边缘的乘积代替；祖先共享会造成相关性。对所有同源同帧、非固定锚节点对组成的集合 $\mathcal P$，并集上界给出

\[
\delta\le\bar\delta=\min\left\{1,\sum_{(i,j)\in\mathcal P}E_{ij}\right\}.
\]

本实现仅针对当前森林中的这些互斥约束。若加入其他合法性条件、依赖父历史的势或跨分量约束，上述条件模型关系需重新核对，不能直接沿用。

### 3.2 任意当前合法动作的 regret

令 $I$ 为当前损失索引，损失是 $I$ 上归一化根分配错误，范围 $[0,1]$。对一个完整合法动作 $a$，

\[
R_0(a)=\frac1{|I|}\sum_{i\in I}(1-M_{i,a_i}),\qquad
\underline R_0=\frac1{|I|}\sum_{i\in I}(1-\max_r M_{ir}),\qquad
g_0(a)=R_0(a)-\underline R_0\ge0.
\]

独立节点最优根未必构成一个合法动作，因此 $\underline R_0$ 只作为 Bayes 风险下界，不直接解码为输出。令 $a_q$ 为与 $a$ 相同合法动作集合上的模型 $q$ 最优动作，由混合分解有

\[
\begin{aligned}
(1-\delta)[R_q(a)-R_q(a_q)]
&=R_0(a)-R_0(a_q)-\delta[R_r(a)-R_r(a_q)]\\
&\le g_0(a)+\delta.
\end{aligned}
\]

因此在 $\bar\delta<1$ 时，

\[
\operatorname{Regret}_q(a)\le
\min\left\{1,\frac{g_0(a)+\bar\delta}{1-\bar\delta}\right\}.
\]

又因为 $\mathrm{TV}(q_0,q)=\delta$，对两个动作分别使用有界损失的 TV 不等式，得到

\[
\operatorname{Regret}_q(a)\le\min\{1,g_0(a)+2\bar\delta\}.
\]

两界可取最小值；空损失范围直接为 0。它们来自条件分解、消息递推与并集界，不应包装成独立原创理论。该界不使用 $Z_K/Z_U$，在星形反例中 $\bar\delta=0$、$g_0(a)=0$，故可识别当前最优动作，而无需保留指数多个旧历史。

这里约束的仍是固定模型 $q$。若与真实后验的 TV 误差为 $\zeta$，真实 regret 比较还需额外的 $2\zeta$ 项；本实现没有 $\zeta$ 的保证，也不能把模型界映射为 HOTA、IDF1 或 AMOTA。
